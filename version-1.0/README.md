# Version 1

This folder contains the manuscript and formalization for version 1 of
*Leakage-Resilient Computation via Matrix Refreshing*.

- [Paper](main.pdf): the current manuscript, updated as it is revised.
- [Lean formalization](lean/): the public definitions and theorem statements,
  complete proofs, and instructions for building and running the comparator.
- [Annotated Lean Reference Specifications](lean/annotated-specifications.pdf):
  a guide to the public definitions and theorem statements.
